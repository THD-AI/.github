# Getting help

To display a project, use the [showroom submission form](https://github.com/THD-AI/thd-ai.github.io/issues/new?template=project-submission.yml). Personal and university projects are welcome; the repository can stay in your account.

- **A project bug:** open an issue in that project with steps to reproduce it.
- **Learning or GitHub questions:** use [Q&A](https://github.com/orgs/THD-AI/discussions/categories/q-a).
- **A new project or collaborators:** use [Ideas](https://github.com/orgs/THD-AI/discussions/categories/ideas).
- **Membership, clubs, or collaboration:** email [Alexander](mailto:alex.rudaev@outlook.com). Coffee meetups are welcome.
- **Private concerns or access problems:** use email rather than a public issue.

For official university matters, use [THD](https://www.th-deg.de/) and [iLearn](https://ilearn.th-deg.de/). This community cannot resolve enrolment, assessment, or timetable decisions for the university.
