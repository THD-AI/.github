# THD AI – a shared place for independent projects

A project showroom and collaboration space for people around Deggendorf Institute of Technology. Personal work and university projects sit alongside one another. People choose their own ideas, pace, and collaborators.

- [The showroom](https://thd-ai.github.io/)
- [Public organization profile](profile/README.md)
- [Share a project](SHOWCASE.md)
- [Project directory](PROJECTS.md)
- [Contribute and start something](CONTRIBUTING.md)
- [Community conduct](CODE_OF_CONDUCT.md)
- [Get help](SUPPORT.md)
- [Brand and artwork credits](BRAND.md)
- [Visual archive](archive/README.md)

This repository supplies community defaults to repositories that do not define their own. Project-specific licences, attribution, contribution rules, and maintainer decisions take precedence.

Conversations live in [organization Discussions](https://github.com/orgs/THD-AI/discussions), backed by the existing `AIN-Community-Hub-WS23` repository. Its historical URL is retained so old links keep working. The website and its validation, publishing, and submission workflows live in [thd-ai.github.io](https://github.com/THD-AI/thd-ai.github.io).

For membership, collaboration, or a coffee and a useful idea, contact [Alexander](mailto:alex.rudaev@outlook.com). This is an independent space, without university endorsement.
